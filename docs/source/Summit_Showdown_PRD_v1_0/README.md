# SUMMIT SHOWDOWN — PRD and production handoff v1.0

Prepared 21 September 2026. This pack specifies an original WebGL fighting game with selectable leader avatars and a Laya-controlled opponent.

## Start here
Read `PRD.md` or `Summit_Showdown_PRD.docx`. Use `Summit_Showdown_Production_Tracker.xlsx` for editable planning and the `production/` CSV/JSON files for implementation-facing metadata. The artist brief and implementation brief can be handed to their respective owners.

## Included
- Complete PRD: product, combat, Laya, art pipeline, animation, rendering, capture, operations, rights and release gates.
- 66 reusable asset requirement rows; 68 animation register rows (62 shared V1, four per leader and two V2); 22 move/action entries (21 V1, one V2).
- 58 identified must-have requirements and ten estimated work packages.
- 52 proposed geographic/catalogue coverage entries. These are not a current-officeholder directory; names/sources are intentionally unfilled and publication is blocked.
- Four normalised JSON Schemas and validated illustrative examples.
- Laya policy brief, gated implementation brief and character-artist commissioning brief.

## What is not included
No finished game, executable backend, trained combat checkpoint, produced/licensed character assets, real leader reference photographs, font binaries, purchased assets or passed release tests. Numbers in example responses are illustrative. Work estimates and performance/asset budgets are proposals, not supplier quotations or observed results.

## Source of truth
The PRD defines semantics and acceptance. Registers supply versioned initial planning data. The JSON Schemas validate the proposed integration boundary; they are not the upstream Laya wire format. Runtime legality and cross-field tests remain necessary. Do not label a source list or a successful schema check as proof that the actual game works.

## Sources and publication
External sources are recorded in PRD section 27. Public identity cards need official-office verification and separate asset/rights approval. All avatars share the same mechanics. All gameplay/video presentation remains visibly fictional and politically non-evaluative.

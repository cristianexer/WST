# Contract examples

All files in this folder are fictional integration fixtures, not measured model output, produced assets, verified officeholders or an executable replay. The numeric decision scores and timings are illustrative. Referenced asset/replay payload files are not included because they have not been produced.

Schemas validate shape and selected publication conditions. Runtime checks must also validate request/response correlation, timing, legal actions, score normalisation, version compatibility and asset hashes. A published leader record requires a real source, timestamp and approved reviews; its placeholder name must be rejected by editorial validation.

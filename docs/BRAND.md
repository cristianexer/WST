# WST brand package

The brand assets were generated with the built-in image generation tool and copied into the project with their generated pixels unchanged. Both PNGs were checked for an alpha channel before use.

## Generated assets

- `apps/web/public/assets/brand/wst-brandmark.png` — 1536 × 1024 transparent header/social mark.
- `apps/web/public/assets/brand/wst-icon.png` — 1254 × 1254 transparent square app mark.
- `apps/web/public/favicon.png` and `apps/web/public/apple-touch-icon.png` — copies of the square mark.

The generated mark combines an angular, legible WST monogram with a summit peak and globe arc. It uses charcoal, warm ivory, warm gold, and a restrained cyan accent. No political imagery, people, weapons, or watermark were requested.

## Prompt provenance

The primary prompt requested a premium transparent logo for “WST” / “WORLD SUMMIT TOURNAMENT”, an original angular WST monogram fused with a stylized summit peak and minimal globe arc, subtle combat energy, exact readable WST lettering, charcoal black, warm ivory, warm gold, restrained cyan, crisp vector-like geometry, generous clear margin, and no extra words, people, flags, political imagery, weapons, or watermark.

The square companion prompt requested the same identity as a compact favicon/app icon: an angular WST monogram, one summit peak, a restrained globe arc, exact readable letters, generous margin, crisp small-size geometry, the same palette, genuine alpha transparency, and no extra words or watermark.

## Publishing metadata

`apps/web/index.html` uses the expected GitHub Pages canonical URL `https://cristianexer.github.io/WST/` for canonical, Open Graph, Twitter, and `VideoGame` JSON-LD metadata. The project includes robots and sitemap files for that expected URL; these files do not claim that the site is currently deployed.
